# Security policy

If you find a vulnerability, please report it privately through GitHub:
**Security → Report a vulnerability**
(https://github.com/lobsterscollide/hardened-api/security/advisories/new).
Please don't open a public issue for security problems.

This project is shared as-is and is not actively maintained, so a response is
not guaranteed. If you rely on it, fork it and apply fixes in your fork.
